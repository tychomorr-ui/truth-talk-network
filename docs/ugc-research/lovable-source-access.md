# Lovable source access and credit-use options

The session has no Lovable MCP connector, and `manus-config config load --search Lovable` found no Lovable connector selection. No Lovable login, project operation, code edit, deploy, or credit usage was attempted.

Lovable’s official Code Mode documentation says a project member with edit access can download a full codebase ZIP through Code → Download codebase or Project settings → Git. The ZIP option is for paid plans and can be restricted by an Enterprise workspace administrator. Browsing files and downloading code do not consume AI credits; manual code edits and saves also do not consume credits, though saved edits apply directly to the project and can affect its version history. Git sync is another full-source path, but it creates a two-way link between project and repository, so it is not a read-only export. [1]

Lovable’s official credit documentation says Plan mode costs one credit per message plus any subagent research it invokes. Build mode costs vary with task complexity and completed work. An ordinary request to Lovable about usage also consumes credits. Therefore, a code export or read-only inspection is the more conservative way to provide source for an audit; the five credits need not be spent to retrieve the code. [2]
